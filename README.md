# Hookvale Games — hookvalegames.com

Static site for Hookvale Games Pty Ltd. Hosted on GitHub Pages.

## Files

- `index.html` — landing page
- `terms.html` — Terms & Conditions
- `privacy.html` — Privacy Policy
- `styles.css` — site styles
- `site.js` — page interactions
- `tweaks.js` — in-page tweaks panel
- `CNAME` — custom domain config for GitHub Pages

## Local preview

Open `index.html` in a browser. No build step.

## Deploy

GitHub Pages serves from the `main` branch root. Custom domain
`hookvalegames.com` is configured via the `CNAME` file and the
repo's Settings → Pages screen.
